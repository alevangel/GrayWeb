# Privacy policy

GrayWeb does not collect, store or share any personal data.

- **No data collection.** GrayWeb has no analytics, telemetry or crash reports.
- **No network requests.** GrayWeb does not contact any server. All code is included in the extension package.
- **Page content.** The content script only adds a style to the page. It does not read the text, the forms or any other content of the page.
- **Your configuration.** Rules and settings are stored in the extension storage of your browser. If your browser synchronizes extension data with your account (for example, Chrome Sync or a Firefox Account), the configuration is synchronized by the browser, under the privacy policy of the browser vendor. You can export and delete the configuration at any time from the settings page.

## Permissions

| Permission          | Use                                                                                                                                             |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `storage`           | Keeps the rules and settings.                                                                                                                   |
| Access to all sites | Lets the content script apply the filter before the page appears, and lets the popup read the URL of the current tab to show the matching rule. |
